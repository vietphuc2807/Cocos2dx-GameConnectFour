----- ĐỂ CHẠY FILE MẪU TRÊN GITHUB 

B1: Tạo project cocos2dx mới, xong build cho chạy thành công

B2: Tải project mẫu trên GitHub https://github.com/vietphuc2807/Cocos2dx-GameConnectFour.git

(Mở cmd, chạy lệnh 
git clone https://github.com/vietphuc2807/Cocos2dx-GameConnectFour.git)

B3: Copy hai thư mục Classes và Resource của Project Git thay thế vào Project Cocos đã tạo ở bước 1

B4: Xóa các file đã có trong classes Visual, rồi bỏ các file .cpp .h trong thư mục classes project git vào visual lại 

-> nếu lỗi resource thì copy thư mục resource vào proj.win32\bin\(Tên_Project)\Debug, thay thế thư mục resoure hiện tại
